# AmpliWidgets (Public Pages & Support Repository)

This public repository hosts the official GitHub Pages landing page, privacy policy, and support documentation for **AmpliWidgets**, a native AV receiver remote and interactive iOS 27 widget suite for Marantz and Denon audio equipment.
